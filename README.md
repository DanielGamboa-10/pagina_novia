# Un Detalle Especial Para Ti ❤️

Una página web romántica, interactiva y didáctica hecha especialmente para Karen Sofía.

## ✨ Características y Dinámicas
- **Sobre de Bienvenida 3D**: Sello de cera interactivo que revela el detalle al tocarlo.
- **Contador en Tiempo Real**: Días, horas, minutos y segundos compartidos juntos.
- **Vales "Raspa y Gana"**: Tarjetas doradas interactivas con vales y sorpresas personalizadas.
- **Trivia de Pareja**: Preguntas interactivas con puntuación y retroalimentación tierna y divertida.
- **El Frasco de las 100 Razones**: Selector aleatorio y visualizador completo de las 100 razones para amar a Karen.
- **Carta de Amor en Pergamino**: Carta personalizada con dedicatoria, promesas y cariño.
- **Galería de Recuerdos Polaroid**: Fotos y anécdotas inolvidables con visor lightbox.
- **Pregunta Final con Botón Escurridizo**: El botón "No" se escapa al intentar tocarlo y el "Sí" celebra con confeti.
- **Música Romántica**: Reproductor con canción de fondo y sintetizador armónico Web Audio API.
- **Diseño 100% Responsivo**: Totalmente adaptado para celulares y computadoras con estética glassmorphism moderna.
